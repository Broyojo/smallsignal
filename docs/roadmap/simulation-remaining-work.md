# Simulation: Remaining Capabilities

Status: proposed
Owners: simulation integration and release owners.

## Legacy experiment conversion

The helper converts simple version-1 sidecars; advanced bindings, plans, named
outputs, device selections, measurements and corners can block it. Open:
whether broader translation is worth it. Meanwhile return located conversion
limits. An extension must prove equivalent circuit, conditions and capture per
case and refuse ambiguity without changing the saved input.

## Repeated Noise provenance

Multiple or reordered Noise invocations keep raw records with a pairing
limitation. An extension needs capture-backed association and tolerances, never
title or order guessing.

## Release acceptance

GUI, public MCP and cross-Project acceptance need recorded evidence for each
affected release (edits, error/repair, Cell import, execution, Specs/raw/CSV,
Batch, save/reload, access); a deployment's smoke checks do not imply it.
VACASK follows its [qualification rule](vacask-migration.md).

## Deferred extensions

Live cross-Project synchronization; Cloud-persistent result archives; Monte
Carlo, optimization, automatic circuit modification, other simulators, uploaded
Verilog-A, model marketplaces. Lossless two-way raw-SPICE/Canvas topology sync
is not promised.
