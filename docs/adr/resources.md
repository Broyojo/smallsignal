# Component Resources and Evidence

Status: `accepted`
Owners: `packages/components`, `packages/devices`, `packages/symbols`, `references`

Each built-in component is authored once and its runtime projections generated
([Symbol DSL](../specs/symbol-dsl.md),
[component definitions](../../packages/components/README.md)), so device and
symbol registries cannot drift. The
[Razavi visual contract](../specs/razavi-visual-contract.md) owns reviewed
evidence, with a direct source crop as witness so candidates cannot grade
themselves. [Research sources](../../references/README.md) are pinned, narrow
inputs, never product dependencies.
