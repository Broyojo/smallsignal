# Domain Documentation

Single-context: root GLOSSARY.md and docs/adr/. Read the relevant terms and
ADRs first and use their vocabulary; domain-modeling creates missing files when
a term or decision is clarified. The glossary links specs for detail; ADRs
follow the [retention test](../adr/README.md#retention-test). When work
overturns a recorded decision, state the conflict and decide before editing.
